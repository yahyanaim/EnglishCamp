# Internet images inside all 100 lessons

There are **35 curated internet assets across 102 image placements in 100 lessons**, with 25 image explanations per course. Images are deliberately reused where the same setting teaches a different skill; every lesson has its own prompt, explanation and exact insertion anchor. The speaking-comparison and maps/processes modules each use two images.

The selection includes actual photographs, an English compass, a published atmospheric-composition illustration, a NASA water-cycle illustration and the existing credited historical NASA/JPL graph. Search results were inspected visually before acceptance. Rejected results included a printing-circuit detail, a different craft returned by a pottery search, a template pie chart and a compass labelled in another language. Creator credit missing from API metadata for the beakers was recovered from the original Commons file page: Jaeger5432, not the later re-uploader.

Images follow the complete relevant teaching section and precede its next application. Where an image and the approved concept diagram support the same section, the concrete image comes first. The existing 100 diagrams remain. Current routes suppress the older end-of-lesson gallery, avoiding duplicate visuals. A jump link takes the learner directly to the inline images. Study pages show the theory; focused practice keeps the existing theory disclosure.

Every image has a text alternative, a visible teaching caption, creator and source credit, a licence or reuse-policy link, and a full-size view. Portraits use a narrower maximum width; landscape images retain their aspect ratio. Transparent diagrams use white surfaces so their original labels stay legible in both themes. Files are served locally and lazy loaded with intrinsic dimensions. The fonts, global styles, narration, original teaching blocks, practice tasks, scoring and saved-attempt signatures are unchanged.

Observation, interpretation and original teaching examples are distinguished. The library notice is explicitly historical, not current access advice. The atmospheric illustration does not print exact percentages; lessons do not invent them. Numerical transfer datasets are labelled as invented and do not purport to be measurements from the photographs. Health and environmental pictures do not prove causal outcomes or reveal the pictured people’s experiences.

The [current manifest](../public/media/courses/lesson-images/manifest.json) records source files, creators, reuse terms, downloads, dimensions and SHA-256 checksums. Thirty-four newly selected assets are under `public/media/courses/lesson-images/`; the existing credited NASA/JPL chart is reused from `public/media/courses/sourced/`. The previous assets remain archived for compatibility. Image licences apply to their respective files rather than changing the licence of the application as a whole.

Validation is recorded in the task’s `outputs/lesson-images-2026-10-29/` directory. It includes source selection, contact sheets, exact lesson coverage, preservation tests, route checks, responsive browser checks and representative screenshots. These checks establish delivery and compatibility, not measured learner outcomes.

Validation results: **96 tests passed**, TypeScript passed, the isolated production build passed, and lint completed with no errors and 25 existing warnings. All **200 lesson routes** passed, all **35 served image files** matched their recorded checksums, and **all 100 lesson layouts** fit at **320 CSS pixels**. Thirty-three representative desktop pages covered every one of the 35 source images. Focused-practice theory and the image-answer disclosure were verified in the browser. The 320px checks use rendered DOM geometry because viewport-override screenshots are unreliable in this browser; normal-width screenshots document the visual result.
