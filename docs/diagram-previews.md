# Inline lesson illustrations — complete coverage

All **100 lessons** across the four courses now display a subject-specific illustration beside an explicit teaching section, before the next application. The three approved previews remain: a word-family tree, tense timelines and an article decision tree. The remaining **97 lessons** now use individually authored visual examples rather than the earlier three-branch recap display.

The 97 examples use 11 formats: contrasts, linked sequences, argument development, sentence relationships, source/evidence trees, zero-based numerical comparisons, review cycles, decision trees, compass orientation, speech prominence and hypothetical alternative causal paths. A format is selected for the concept being taught. The examples are original; numerical datasets are explicitly fictional. Conditional permission, restrictions, uncertainty and scope remain visible rather than becoming universal rules.

Each diagram has a wide composition and a separately arranged narrow composition, an accessible title and complete description, and a visible explanatory caption. Shapes and labels use the existing theme variables and fonts. There are no external image dependencies or additional packages. The previous 100-record principle registry remains as source data; these illustrations replace its recap display on every lesson route.

Placement uses one exact existing callout heading per lesson. For the 97 new diagrams, the illustration follows that explanation and its associated paragraphs/tables, before the next callout. Original teaching blocks render in their original order. Both study and focused-practice routes receive only the selected diagram metadata. The existing theory disclosure and jump link continue to work.

The existing curriculum, activities, answers, saved-attempt signatures, XP, narration and global style files are protected by the preservation checks. Captions that previously referred to different examples were rewritten for their new illustrations, including the known-price/not-given distinction, concession transformations and exact repetition versus paraphrase.

Validation: **91 tests passed**, TypeScript passed, lint has no errors (25 existing warnings), and the isolated production build passed. Browser geometry checks cover all 100 lessons at 1600 and 320 CSS pixels. A pronunciation-label collision found in the first desktop pass was corrected and rechecked. Mobile screenshots from the viewport override are unreliable in this browser, so the 320px evidence uses rendered DOM geometry. Representative compositions were also inspected visually in the normal browser view.

The preview is served by the isolated QA checkout on port 3027. The original server and original protected course content are untouched. These checks establish delivery and compatibility; they do not measure learner outcomes or change the README’s editorial estimate of course sufficiency.

The original three grammar previews were checked against:

- [British Council: word formation](https://learnenglishteens.britishcouncil.org/exams/grammar-vocabulary-exams/word-formation)
- [Cambridge: present perfect continuous](https://dictionary.cambridge.org/grammar/british-grammar/present-perfect-continuous)
- [British Council: articles](https://learnenglish.britishcouncil.org/free-resources/grammar/a1-a2-grammar/articles-a-an-the)
