# Optional placement, personal timetable and short conversations

3 November 2026.

- Signing in with a new name offers an optional 40-question check. Skipping opens the dashboard. Existing names are not prompted again on every reload. The check is also accessible from the learner menu and Study Plan.
- Forty original items cover language use, vocabulary and short reading: eight editorially graded items per A1–C1 band, including four language-use, two vocabulary and two reading items. The result is an unstandardised study starting estimate, not a validated full CEFR assessment. Speaking, listening and extended writing are not tested. To reach a band, learners need at least 6/8 there and 5/8 in each preceding band; gaps lead to a conservative recommendation.
- Learners can pause and resume. All forty answers, including “I’m not sure”, are required for a result. Explanations appear only after submission. Previous completed attempts remain with the same local learner. Retaking does not award XP, change badges or complete lessons.
- Named completion certificates are generated entirely in the browser as one-page PDFs. Native canvas renders Arabic names with correct shaping. The certificate explicitly states that it is an internal placement estimate without accreditation or public verification. It is not an IELTS, TOEFL or institutional CEFR qualification.
- Study Plan offers a four-week schedule with local start date, weekdays, time, 15/25/40/60-minute sessions and an everyday/IELTS/TOEFL/B2 First goal. Beginners get everyday foundations; B1 learners get B2 foundation lessons before full exam preparation. More advanced plans link to existing course lessons. The weakest measured area comes first, with listening and speaking still included. Every session has recall, study and practice time. A timetable is a starter plan, not a promised level gain.
- Calendar export produces a local RFC 5545 .ics file with individual events, UTC times derived from the learner’s local calendar date and time, escaped text and folded UTF-8 lines. Invalid dates and nonexistent local daylight-saving times are rejected. Import is optional, requires no connected calendar account, and creates no events until the learner imports the file. Import once; later timetable changes do not update an already imported calendar.
- Placement answers, results and timetable use the existing name-scoped session storage. Same name restores them within the tab; another name gets separate records. Deleting a named session removes its placement data along with its learning records. Closing the tab ends session storage. No new server endpoint or learner-data upload was introduced.
- Shadowing now shows nine real two-speaker communication extracts from VOA videos. Every full original video is 59–61 seconds. The player opens on the timed conversation rather than instructor explanation. Exam-teaching and pronunciation-only choices are removed from the visible playlist. Collection and exam-skill selectors are removed; topic badges, sentence replay, synchronized transcript, Microsoft model audio and the existing YouTube frame remain.
- The 103 illustrated A1–A2 vocabulary cards share one collapsed “Words” lesson in the cheat sheet. Body, colors, home, family, café, office, airport, clothes, time and months are subheadings inside that lesson, like the Position lesson. Older topic anchors still open and scroll into Words. Grammar and position lessons remain intact; print expands Words as well.

References: Council of Europe CEFR descriptors and self-assessment grid distinguish receptive, productive and interactive abilities, so this limited check is labelled conservatively. RFC 5545 defines the exported calendar format. Existing verified VOA source IDs and dialogue timing evidence are retained in `shadowing-timings.ts` and the prior upgrade QA source archive.

Validation: automated tests cover grading, missing and invalid answers, name isolation, restoration and deletion, actual course links, beginner placement, session minute totals, invalid dates, daylight-saving changes, UTF-8 calendar folding and escaping, stable event IDs and PDF cross-reference offsets. Browser QA also checks first sign-in, skipping, resuming, completion, PDF downloads (Latin and Arabic names), calendar download, mobile layout, conversation playlist and the single Words category.
